# LinkCam OBS Plugin

Fonte nativa "LinkCam" no OBS Studio. Lê os frames que o app do PC publica em memória compartilhada e permite várias câmeras ao mesmo tempo.

**Stack:** C · CMake · `obs-plugintemplate` oficial do OBS
