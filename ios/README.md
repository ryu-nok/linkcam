# LinkCam iOS

App do iPhone, com as mesmas telas e o mesmo protocolo do Android.

**Stack:** Swift · SwiftUI · AVFoundation · VideoToolbox · Network.framework (Bonjour)

Precisa de Mac com Xcode e conta Apple Developer para distribuir (TestFlight / App Store).
